# 00 — Brief

**Reads:** The user's request and relevant project requirements.

**Produces:** `brief.md` with the user, task, success condition, platform, scope, mode, constraints, known research, and unknowns. State the review breadth (focused or whole product) and the permitted deliverable (findings, visual handoff or implementation). Record the source of each material claim.

**Check before handoff:** The task is concrete enough to review; the review does not assume missing user research. Ask the user only if a missing goal or material product-direction conflict blocks progress. Freeze a version of the brief for independent reviewers.

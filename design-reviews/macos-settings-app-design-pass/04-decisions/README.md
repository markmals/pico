# 04 — Decisions

**Reads:** The shortlist, votes, brief, and evidence.

**Produces:** `decisions.md` for accepted, deferred, and rejected changes, with reason, owner, and links to findings and user needs. For a visual council run, link the versioned design selection, UX review and current handoff under `visual/`. Update the project-level decision index when one exists.

**Check before handoff:** The rationale is understandable without conversation history. Mark any decision that supersedes an earlier one. Do not call a design effective simply because it was chosen.

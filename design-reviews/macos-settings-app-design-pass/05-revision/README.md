# 05 — Revision (authorized mode only)

**Reads:** Accepted decisions and the target project's current state. When a visual council is involved, use its reviewed handoff and selected renders and confirmed design-to-code mapping for the design details. Record material guesses, how they were resolved, and any departure from the reviewed design.

**Produces:** `changes.md` with changed files or surfaces, rationale, scope, and any implementation limits. Keep before evidence intact.

**Check before handoff:** Changes stay within the user's authorization and preserve user-owned data. Fix a wrong upstream brief or decision before polishing downstream implementation. In review-only mode, leave this stage unused and record that no changes were made in the final summary.
